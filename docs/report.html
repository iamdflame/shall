Ambiguity is a compile error.

Six independent language models were handed the same specification and asked to implement it. Nothing else. They returned three different programs — and the disagreement between them is not noise to be averaged away. It is the measurement.

How the error is found

Nothing here asks a model whether a sentence is ambiguous. Asking would return an opinion. Running returns evidence.

1

Every reader gets the identical question

Byte-identical instructions, byte-identical specification, no knowledge that other readers exist. A reader that knew it was being compared would hedge toward the obvious interpretation — which is the exact bias being measured.

2

Readers span generations, not sizes

An earlier roster of five same-generation variants passed a specification a human would have questioned: every member resolved it by the same shared convention. One even wrote a comment noting the ambiguity before silently picking a side. Training lineage is closer to independence than parameter count.

3

Behaviour is compared, never source code

Two correct implementations of one requirement often share no lines at all. Each candidate is executed against every probe in an isolated sandbox, and its results concatenate into a behaviour vector. Identical vectors are the same program, whatever the code looks like.

4

A split is an error, even with a majority

Four readers against two does not resolve anything. A plurality is evidence about which interpretation is more popular — which is precisely the question a specification exists to settle.

Agreement is not correctness

Readers can agree on a program the specification never asked for, and a consensus check alone would call that a clean build. So a second pass turns each clause back into test cases and runs the built program against them.

∴

The expectations are themselves filtered by consensus

A model asked what a clause requires can be as wrong as one asked to implement it. Several readers propose expectations independently, and only the ones they agree on are kept. A case they cannot agree about is not evidence about the program — it is more evidence about the prose, and it is reported as disputed rather than quietly dropped.

  CONFORMANCE  100%  11/11 derived cases hold

    + 1.1   THE SYSTEM SHALL split the text on runs of whitespace…
    + 2.1   THE SYSTEM SHALL retain a token only when that token is…
    + 3.1   THE SYSTEM SHALL return how many tokens were retained

The fix is a sentence

The compiler does not repair the code. It names the words that failed, and the author writes better ones.

The system shall split the text on runs of whitespace and treat each resulting non-empty run as exactly one token, no matter which hyphens, apostrophes, digits or punctuation marks it contains
